# Security Policy

Please do not submit real secrets, access tokens, customer data, private endpoints or exploit artifacts containing sensitive information in public issues.

For a vulnerability in this repository:
1. Do not weaponize or publish a working exploit chain.
2. Provide a minimal reproduction in an isolated environment.
3. Include affected version, impact, prerequisites and suggested mitigation.
4. Contact the maintainers privately before public disclosure.

This project intentionally avoids shipping destructive exploit automation. Report requests to add credential theft, persistence, arbitrary remote execution, stealth, or data-exfiltration capabilities as out of scope.
