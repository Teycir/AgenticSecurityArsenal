# Agentic Security Arsenal skills

Each child folder is a portable Agent Skill. Read its `SKILL.md` for the procedure and `asa-skill.json` for machine-readable metadata.

- `scope-authorization` — validate declared scope.
- `security-assessment-planning` — produce manual assessment plans.
- `mcp-server-review` — passively inventory MCP interfaces.
- `openapi-review` — statically inspect OpenAPI JSON.
- `scanner-results-triage` — normalize existing scanner exports.
- `evidence-hypothesis-review` — derive unverified hypotheses from evidence.
- `investigation-workflow` — track evidence-led sessions with serialized writes.
- `local-security-labs` — run deterministic synthetic exercises.

Do not load every skill by default. Select the smallest useful set. Skill metadata does not grant target authorization.
