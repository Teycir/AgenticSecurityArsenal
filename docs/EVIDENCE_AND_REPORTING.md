# Evidence and Reporting Standard

## Finding structure

```text
ID:
Title:
Affected component:
Technique ID:
Severity:
Confidence:
Authorization / scope reference:
Prerequisites:
Summary:
Expected security behavior:
Observed behavior:
Root cause:
Impact:
Reproduction boundary:
Evidence references:
Remediation:
Retest:
Limitations:
CWE:
OWASP mapping (taxonomy + version):
MITRE ATLAS mapping (if applicable):
```

## Evidence quality

Prefer raw, redacted request/response pairs, deterministic test fixtures, server-side authorization logs and repeatable test scripts. Screenshots are supplementary evidence, not a replacement for protocol-level records.

Separate:
- Directly observed facts.
- Researcher interpretation.
- Inferred production impact.
- Unverified hypotheses.

Never publish live credentials, session cookies, private customer data or unredacted personal information.
