# v1.4 investigation capabilities

## Workflow

1. Validate an engagement manifest with `agentsec scope-check`.
2. Map an API from an OpenAPI JSON document using `agentsec openapi`.
3. Optionally make a single benign GET request using `agentsec http-probe`. The exact URL origin must appear in the unexpired scope manifest.
4. Import existing Nmap XML, Nuclei JSONL and Burp XML exports with `agentsec import-scan`. Import is offline.
5. Combine normalized reports with `agentsec hypotheses` to create a review queue for the agent.
6. Verify each hypothesis manually or with a separately approved test; retain original scanner artifacts as evidence.

## HTTP probe contract

`http-probe` and MCP `http_get_probe` issue one GET request to the exact URL supplied. Authorization is checked against the manifest's exact scheme/host/port origin and expiry. The request:
- uses the platform TLS trust store and verifies certificates;
- refuses redirects;
- has a 0.5–30 second timeout;
- reads at most 1 MB and emits at most a 2 KB body excerpt;
- does not crawl, fuzz, follow links, submit forms, or use state-changing methods.

The probe is not a vulnerability scanner. A 2xx response does not establish security, and an HTTP error response is not itself a vulnerability.

## Importer contracts

- `openapi_analyze`: currently accepts OpenAPI JSON objects. It inventories paths and methods and flags state-changing methods as informational review candidates. It does not prove missing authorization.
- `nmap_xml`: imports host addresses, port state and service metadata.
- `nuclei_jsonl`: imports template ID, name, severity, matched URL and extracted results.
- `burp_xml`: imports issue metadata and available descriptions/evidence fields.
- `hypothesis_generate`: creates unverified hypotheses from normalized `observations` arrays. It does not convert scanner severity into confirmed vulnerability status.

Treat all imported artifacts as untrusted input. XML parsing uses the standard library; do not ingest exports from untrusted parties in environments where parser hardening is required without reviewing the source and deployment boundary.

## Agent use

Use `agentsec mcp-serve --print-manifest` to discover schemas. New MCP tools reject undeclared arguments. For `http_get_probe`, supply the full scope JSON string and URL. The server validates the manifest, including expiry, before making the request.
