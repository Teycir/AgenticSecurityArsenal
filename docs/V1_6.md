# v1.6.0 — skills-first usability release

## What changed

- Added eight focused, portable Agent Skills with `SKILL.md` instructions and `asa-skill.json` machine-readable metadata.
- Added local skill discovery, display, and validation: `agentsec skills list|show|validate`.
- Added MCP/Python discovery capabilities `skills_list` and `skill_get`.
- Documented permission profiles, execution modes, parallel-safety boundaries, evidence provenance, and human handoff.
- Added an agent quick start, human user guide, architecture overview, and recommended result contract.
- Preserved v1.5 capabilities and existing result shapes. No heavyweight scheduler or agent orchestration runtime was added.

## Validation boundary

Skill metadata is descriptive and helps agents route tasks; it is not an authorization mechanism. The existing scope validator remains authoritative. Parallel-safe labels describe independent work patterns and do not guarantee that target systems tolerate concurrency. Shared investigation session writes must be serialized.
